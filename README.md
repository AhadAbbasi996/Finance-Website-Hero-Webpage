# Finance Website — Hero Webpage

A modern, responsive finance landing-page hero section built with **HTML & CSS**, featuring a cinematic animated background, responsive navigation, smooth entrance animations, and mobile-friendly interactions.

## ✨ Features

- Responsive desktop, tablet & mobile design
- Animated hero text and CTA buttons
- Cinematic looping video background
- Responsive mobile navigation menu
- Reduced-motion accessibility support
- Modern glassmorphism UI elements
- Plus Jakarta Sans typography

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Run Locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/AhadAbbasi996/Finance-Website-Hero-Webpage.git
cd Finance-Website-Hero-Webpage
```
